# Cert-generator

基于 Streamlit 的内审员证书批量生成工具。

## 快速生成

1. 打开“选择标准”弹出框，按每行两个标准的布局勾选一个或多个常用标准；点击页面空白处即可关闭。关闭后页面会显示已选标准标签，也可以一键清空或填写自定义标准。
2. 在同一个日历控件中选择培训日期：选择一天为单日，继续选择结束日期为连续日期；系统会自动生成中文日期格式。
3. 每行粘贴一个姓名，或直接从 Excel 粘贴“姓名、身份证号”两列；页面会即时显示人数与脱敏预览，并自动清除空行和重复姓名。
4. 如有需要，展开“更多：自动生成证书编号”并设置编号规则。
5. 在生成前检查卡确认标准、日期、人数和模板，然后点击“开始生成”，下载合并 Word 或包含单独证书的 ZIP。

页面默认使用仓库内置的 Word 模板；只有需要临时替换版式时才需展开“更换为其他 Word 模板”。

## 完整信息录入

需要为每名学员填写不同的证书编号、身份证号、日期或标准时，可使用 Excel 上传或网页表格粘贴模式。18 位身份证号会自动隐藏中间 8 位。

## 修改常用标准

编辑 `standards.json` 即可增删标准。键是页面显示名称，值是写入证书的文字，例如：

```json
{
  "质量管理体系（ISO 9001:2015）": "ISO 9001:2015"
}
```

标准可能换版，请在签发证书前根据培训内容和适用的过渡期确认版本号。
当前预设同时保留 ISO 9001 和 ISO 14001 的 2015、2026 版本，并将日常最常用的标准排在选择列表前面。
食品安全预设同时保留 FSSC 22000 V6.0 和 V7；合规管理体系按 `GB/T 35770—2022/ISO 37301:2021` 写入证书。
其他预设覆盖设施、人工智能、诚信、碳管理、售后服务、测量、物业、食品与农业、社会责任、创新、供应链、水效率、反贿赂、有机产品、知识产权和业务连续性等体系。

## Word 模板变量

内置或上传的 `.docx` 模板可使用以下变量：

- `{{ number }}`：证书编号
- `{{ name }}`：姓名
- `{{ id_card }}`：脱敏后的身份证号
- `{{ date }}`：培训日期
- `{{ standards }}`：标准号

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```
